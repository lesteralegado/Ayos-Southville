# Domain Docs

This repository uses a single-context domain-documentation layout.

## Before exploring

Read these resources when they exist:

- `GLOSSARY.md`
- Relevant ADRs under `docs/adr/`

Missing domain documents should not block work. The domain-modeling workflow creates them when terminology or architectural decisions require documentation.

## Vocabulary

Use terms as defined in `GLOSSARY.md`. Avoid replacing established terms with synonyms. If an important concept is missing, note it for domain modeling.

## Architecture decisions

Surface conflicts with existing ADRs explicitly rather than silently overriding them.
