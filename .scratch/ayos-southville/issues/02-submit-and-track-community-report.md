# 02: Submit and track a community report

**What to build:** Let a verified resident submit a non-emergency roads and drainage, streetlight, or waste collection concern, recover an unfinished draft, receive a stable reference, and follow its initial public timeline.

**Blocked by:** 01: Launch the public pilot and resident accounts.

**Status:** done

- [x] A verified resident can submit a report with category, description, nearby landmark, and required acknowledgements.
- [x] The composer provides clear bilingual guidance, inline validation, and an accessible error summary.
- [x] Unfinished form content is recoverable as a private draft and can be resumed or discarded.
- [x] Potential emergencies are diverted before submission to configurable, clearly presented emergency guidance.
- [x] A successful submission receives a stable human-readable reference and an initial Submitted timeline event.
- [x] Residents can view their submitted reports and the public-safe report detail.
- [x] Ambiguous network failures do not create accidental duplicate submissions and offer a safe retry path.
- [x] Tests exercise submission through the application boundary and verify that private resident data is absent from public responses.
