# 07: Administer and measure the pilot

**What to build:** Let administrators configure who can operate the pilot, what it accepts, where concerns are routed, which emergency guidance is shown, and which privacy-safe outcomes the community can see.

**Blocked by:** 06: Process reports through verified resolution.

**Status:** ready-for-agent

- [ ] Administrators can grant and revoke Resident, Moderator, Coordinator, and Administrator capabilities safely.
- [ ] The system prevents an administrator from accidentally leaving the pilot without a viable administrator.
- [ ] Administrators can manage report categories and responsible destinations without application code changes.
- [ ] Administrators can configure verified emergency guidance separately for English and Filipino.
- [ ] Configuration changes are validated, authorized, and represented in the audit history.
- [ ] The public can view report totals by category and status without accessing private records.
- [ ] The public can view correctly defined median first-response and resolution times.
- [ ] Recurring-area insights apply a privacy threshold and never identify a household.
- [ ] The public can see resident-confirmed resolution totals without individual staff rankings.
- [ ] Tests cover permissions, unsafe configuration attempts, timezone boundaries, empty datasets, median calculations, and privacy thresholds.
