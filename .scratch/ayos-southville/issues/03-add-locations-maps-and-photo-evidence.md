# 03: Add locations, maps, and photo evidence

**What to build:** Enrich reports with private exact locations and protected photo evidence while giving the public equivalent, privacy-safe map and list discovery experiences.

**Blocked by:** 02: Submit and track a community report.

**Status:** ready-for-agent

- [ ] Residents can place an issue on a map and provide private block, lot, or similarly precise location details.
- [ ] Public report reads and map markers reveal only approved approximate locations.
- [ ] Residents can select, preview, remove, resize, and compress supported evidence photos before upload.
- [ ] File type, count, and size limits are enforced before upload and again at the service boundary.
- [ ] Restricted evidence remains unavailable through public asset access.
- [ ] Upload progress, failure, retry, and successful attachment states are understandable on unreliable connections.
- [ ] Residents can browse the same privacy-filtered dataset using either a map or a complete accessible list.
- [ ] Category, status, date, and distance filters are URL-addressable and persist across refreshes.
- [ ] Tests prove that exact locations and restricted media cannot be obtained from public contracts.
