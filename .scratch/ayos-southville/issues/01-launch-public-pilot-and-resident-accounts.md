# 01: Launch the public pilot and resident accounts

**What to build:** Launch a deployable bilingual Ayos Southville experience where visitors can understand the resident-led pilot, browse seeded privacy-safe reports, and create a verified resident account with a private identity and public alias.

**Blocked by:** None (can start immediately).

**Status:** done

- [x] Visitors can clearly distinguish the resident-led pilot from an official government, HOA, NHA, or barangay service.
- [x] Visitors can browse seeded public reports through a responsive list without signing in.
- [x] Public report data excludes reporter identity, contact information, exact location, internal notes, and restricted media.
- [x] Users can switch between English and Filipino, and the preference survives navigation and return visits.
- [x] Residents can register with and verify an email address, sign in, and sign out.
- [x] A resident profile keeps verified identity private and exposes only the chosen public alias.
- [x] Resident-only pages and actions reject unauthenticated access at the application boundary.
- [x] The primary public and authentication journeys are keyboard accessible and covered by behavior-focused tests.
