# Preserve the selected report pin

Status: implemented

The approved public map must use the resident's selected issue pin with the same latitude and longitude. Remove two-decimal rounding from submission, public draft preparation, approval, and public projection. Decimal coordinate inputs must accept the actual selected precision.

Keep coordinate range validation, publication review, and the public data allowlist. Do not expose private household access notes, resident identity, or unapproved photos. Explain in English and Filipino that the approved issue pin becomes public.

Do not automatically rewrite previously published locations from private records: those residents submitted under the previous explanation that exact locations stayed private. This change applies to newly approved pins; no cloud data migration is included.
